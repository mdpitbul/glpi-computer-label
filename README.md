# GLPI Computer Label

Simple GLPI 11 plugin for printing computer asset labels.

## Features

- Adds an "Asset Label" tab to computer assets
- Prints a configurable asset label
- Configurable company name
- Configurable label width and height
- Optional inventory number
- Optional serial number
- Optional QR code linking to the asset card

## Tested with

- GLPI 11.0.6

## Requirements

- GLPI 11.x
- Internet access for QR code generation via qrserver.com
